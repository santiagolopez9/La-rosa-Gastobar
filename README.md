# La Rosa Bar 🌹 - La Candelaria, Bogotá

Sitio web oficial de **La Rosa Bar** en Bogotá (Cra. 3 Este #8-61).  
Diseño boutique y exclusivo inspirado en su emblemática casona colonial azul, portada barroca, cócteles de autor, libros, terraza al aire libre y reseñas verificadas 5.0 ⭐ en Google Maps.

---

## 🚀 Despliegue en GitHub y Vercel

### Paso 1: Subir a GitHub

1. Crea un nuevo repositorio en tu cuenta de GitHub (por ejemplo: `la-rosa-bar`).
2. En tu terminal local dentro de esta carpeta, ejecuta:

```bash
# Si aún no has vinculado el remoto de GitHub:
git remote add origin https://github.com/TU_USUARIO/la-rosa-bar.git

# Subir los cambios a la rama principal:
git push -u origin main
```

*(Si descargas el proyecto en formato ZIP, descomprímelo, abre la terminal en esa carpeta y ejecuta esos dos comandos).*

---

### Paso 2: Desplegar en Vercel (Gratis en 1 Minuto)

1. Ingresa a [Vercel](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** > **"Project"**.
3. Selecciona tu repositorio recién creado (`la-rosa-bar`) y haz clic en **"Import"**.
4. Vercel detectará automáticamente que es un proyecto **Vite**:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Haz clic en el botón azul **"Deploy"**.
6. ¡Listo! En menos de 45 segundos tendrás tu dominio oficial activo (ej: `https://la-rosa-bar.vercel.app`), con certificado SSL HTTPS gratuito y actualizaciones automáticas cada vez que hagas `git push`.

## 🛠️ Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo en http://localhost:3000
npm run dev

# Generar versión de producción optimizada
npm run build
```
